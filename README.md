# ふせんボード

班ごとに書きこめるホワイトボードです。書いたフレームは先生に提出できます。

- ペン・マーカー・消しゴム・付箋・文字・レーザーポインター
- 付箋と文字は UD フォントで表示されます（Windows では UDデジタル教科書体、ほかの端末では BIZ UDPゴシック）
- 複数のフレームを使えます。背景は無地・方眼・ドット・罫線・原稿用紙から選べます
- 同じ班の人とリアルタイムで共同編集でき、ほかの人のカーソルも見えます
- 生徒は「先生に提出」でフレームを送れます。先生は「提出箱」で確認し、ひとことを返せます
- ログインは不要です。生徒は名前と班を入れるだけ。先生は「先生用はこちら」から合言葉を入れます（先生は何人でもOK）

保存先には Google の Firebase（Realtime Database）を使います。下の手順で、先生が一度だけ設定してください（10分ほどです）。
設定をする前でも、ページを開いて「お試しモード」を押すと、その端末の中だけで動きを試せます。

---

## 手順1　Firebase のプロジェクトを作る

1. https://console.firebase.google.com を開き、Google アカウントでログインします
2. 「プロジェクトを作成」を押し、名前（例：`white-board`）を入れて作成します。Google アナリティクスはオフで大丈夫です

## 手順2　ウェブアプリを登録して、設定をコピーする

1. プロジェクトのトップで「ウェブ」（`</>` のマーク）を押します
2. アプリのニックネーム（例：`board`）を入れて「アプリを登録」を押します
3. 表示された `const firebaseConfig = { ... }` の中身をコピーします
4. このリポジトリの `firebase-config.js` を開き（GitHub 上で鉛筆マークから編集できます）、`YOUR_...` と書かれた部分をコピーした値に置き換えて保存（Commit）します

`databaseURL` は手順3でデータベースを作ったあとに表示されます。手順2の時点でなければ、手順3のあとで追加してください。

## 手順3　Realtime Database を作って、ルールを貼る

1. 左のメニューの「構築」→「Realtime Database」→「データベースを作成」を押します
2. 場所は「シンガポール（asia-southeast1）」を選びます
3. 「ロックモードで開始」を選んで作成します
4. 上に表示される `https://…firebasedatabase.app` のアドレスを、`firebase-config.js` の `databaseURL` に入れます
5. 「ルール」タブを開き、中身をすべて消して、このリポジトリの `database.rules.json` の中身をまるごと貼りつけ、「公開」を押します

## 手順4　匿名ログインを有効にする

1. 左のメニューの「構築」→「Authentication」→「始める」を押します
2. 「ログイン方法」で **匿名** を有効にします（生徒も先生も、この方法でつながります）
3. 念のため、「設定」タブ →「承認済みドメイン」→「ドメインを追加」で、`iamochiai-collab.github.io` を追加しておきます

## 手順5　GitHub Pages を公開する

1. このリポジトリの「Settings」→「Pages」を開きます
2. 「Branch」を `main`、フォルダを `/ (root)` にして「Save」を押します
3. 少し待つと `https://iamochiai-collab.github.io/WHITE-BOARD/` で開けるようになります

## 手順6　先生の合言葉を決める（最初の1回だけ）

1. 公開されたページを開き、右上の「先生用はこちら」を押します
2. 合言葉（6文字以上）を2回入れて、「合言葉を決めて先生になる」を押します

合言葉を最初に決められるのは1回だけです。**生徒に配る前に、必ず先に決めてください。**
ほかの先生には合言葉を伝えれば、同じように「先生用はこちら」から先生になれます。生徒には教えないでください。
合言葉が生徒に知られてしまったときは、先生モードの「合言葉を変える」で変更できます。変えると、それまでの先生も新しい合言葉で入り直すことになります。

## 使い方

**生徒**
- ページを開くと、名前と班を聞かれます
- 書いた内容は自動で保存され、同じ班の人にすぐ届きます。ほかの班のボードは開けません
- 下の「先生に提出」で、今のフレームを先生に送れます。先生からの返事は「提出した物」に届きます

**先生**
- 右上の「先生用はこちら」で合言葉を入れると、どの班のボードも開けます。先生用のリンク（例：`https://iamochiai-collab.github.io/WHITE-BOARD/#teacher`）から開くと、合言葉の画面がすぐ出ます
- 「生徒にもどる」を押すと、その端末はふつうの参加者にもどります
- 「班」ボタンから、班の数や名前を変えたり、生徒が班を変えられないようにしたりできます
- 「提出箱」で提出物を見て、「確認済み」の印とひとことを返せます。画像としても保存できます

**班ごとのリンク**
リンクの最後に `#g1`、`#g2` …を付けると、その班が選ばれた状態で開きます。
例：`https://iamochiai-collab.github.io/WHITE-BOARD/#g3`

## 知っておいてほしいこと

- 生徒はログインしないので、同じ端末・同じブラウザで開くと「同じ人」として扱われます。ブラウザの履歴を消したり、別の端末で開いたりすると、名前と班をもう一度入れることになります
- 名前は自分で入れるので、ほかの人の名前を名乗ることは防げません
- Firebase の無料プラン（Spark）では、同時接続は100人まで、データの送受信は月10GBまでです。1クラスで使う分には十分ですが、たくさんのクラスで毎日使う場合は Firebase コンソールの「使用量」を時々確かめてください
- 提出物やボードのデータを消したいときは、Firebase の Realtime Database の「データ」タブから削除できます
