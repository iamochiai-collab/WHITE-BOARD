Firebase の設定がまだです

みんなで書き込んだり提出したりするには、保存先の Firebase をつなぐ必要があります。手順は README にあります。

  1. Firebase でプロジェクトを作る
  2. firebase-config.js に設定を貼りつける
  3. ルール（database.rules.json）を貼りつける

設定の前でも、この端末の中だけで動きを試せます。お試しモードでは、右上の「先生用はこちら」から合言葉なしで先生と生徒を切りかえられます。
